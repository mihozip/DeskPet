# Pet assets

The public source repository intentionally does **not** ship the prototype white-cat PNG files because their redistribution license has not been verified.

DeskPet runs without them and shows a neutral fallback surface. To use your own pet artwork, add four transparent PNG files here:

- `pet_idle.png`
- `pet_listening.png`
- `pet_success.png`
- `pet_sleep.png`

Recommended: 512×512 RGBA, transparent background, consistent character alignment.

Only commit assets that you created yourself or are licensed to redistribute. Asset licensing is independent from the MIT license covering DeskPet source code.
